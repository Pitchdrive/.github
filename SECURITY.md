# Security policy

If you believe you have found a security vulnerability in a Pitchdrive website, service or repository, please tell us privately.

## How to report

Email **security@pitchdrive.com** with:

* the affected URL, service or repository;
* the steps to reproduce the issue, and what an attacker could do with it;
* your name or handle, if you would like to be credited.

Please do not report security issues through public GitHub issues.

## Ground rules

* only test with accounts and data that are your own;
* do not access, change or delete data that belongs to someone else;
* do not run denial of service, spam or social engineering tests;
* give us reasonable time to fix the issue before you disclose it.

We do not run a bug bounty program.
